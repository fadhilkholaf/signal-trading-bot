# Security policy

## Protect secrets

Never commit `.env`, Telegram bot tokens, chat IDs, exchange credentials, SQLite databases, or private deployment files. Use `.env.example` as the configuration template.

This project is designed to use public exchange market-data endpoints only. It must not be given exchange trading credentials.

## Reporting a vulnerability

Please report security issues privately to the repository maintainers rather than opening a public issue containing credentials or exploit details.
